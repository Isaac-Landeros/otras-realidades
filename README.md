# Otras realidades

Interactive visual exercises (p5.js) for understanding the realities of other countries: start with your own, then compare. Part of [Isaac Landeros' research](https://www.isaaclanderos.com/research).

Ejercicios visuales interactivos para entender realidades de otros países: primero el tuyo, después la comparación.

- **01 · Territorio y gente** — https://isaac-landeros.github.io/otras-realidades/01-territorio/

Datos: Banco Mundial (CC BY 4.0), Naciones Unidas, FMI, mledoze/countries (ODbL). Tipografías: Archivo e IBM Plex Mono (SIL OFL). p5.js (LGPL 2.1).
